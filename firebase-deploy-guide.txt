3D 역사 테마 박물관 배포 안내

1. Firebase 연결 설정
- Firebase 콘솔에서 프로젝트를 만듭니다.
- 웹 앱을 추가한 뒤 firebaseConfig 값을 복사합니다.
- history-museum-funding-firebase.html 파일의 FIREBASE_CONFIG 부분에 붙여 넣습니다.

2. Firestore 만들기
- Firebase 콘솔에서 Firestore Database를 만듭니다.
- 테스트용으로 먼저 시작한 뒤, 수업 후 규칙을 조정하세요.

수업 중 임시 규칙 예시:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /historyMuseumApps/mainClassroom {
      allow read, write: if true;
    }
  }
}

3. 배포
- Netlify, GitHub Pages, Firebase Hosting 중 하나에 history-museum-funding-firebase.html 파일을 올립니다.
- 파일 이름을 index.html로 바꾸어 올리면 주소가 깔끔합니다.

4. 학생 배포 전 확인
- 선생님 브라우저와 다른 브라우저 또는 휴대폰에서 같은 링크를 엽니다.
- 한쪽에서 유물을 등록했을 때 다른 쪽에서도 보이면 공동 저장 연결이 완료된 것입니다.

주의
- firebaseConfig를 입력하지 않으면 학생 공동 저장이 아니라 각 브라우저에만 저장됩니다.
- 학생들이 올리는 이미지는 현재 Firestore 문서 안에 저장되므로 너무 큰 이미지는 피하는 것이 좋습니다.
